Why Unity Exists

Unity SMP was born from a simple dream: to create a space where creativity knows no bounds andfriendships flourish naturally. What started as a passion project has blossomed into a thrivingworld where players come together for something more than just the game. Frequently Asked Questions

Find answers to common questions about Unity SMP. Can't find what you're looking for? Join ourDiscord and ask!

Getting Started

How do I join Unity SMP?

To join Unity SMP, you'll need watch Imperial Jedi on Twitch, so we can get to know you andsee if you're a good fit for us and if we are a good fit for you. Then join our Discordserver and submit your application and once it isreviewed and approved, you'll be whitelisted and can start playing. Check out our Join page for detailed steps.

What version of Minecraft do you use?

We currently run on the latest stable version of Minecraft Java Edition, which is 1.21.9.Check our Discordannouncements for the exact version number and any modpack requirements.

Is the server free to play?

Yes! Unity SMP is completely free to play. We're a community-driven server that relies on thepassion and dedication of our players.

What are the age requirements?

Players must be at least 18 years old to fullyenjoy the community experience and follow our guidelines. No players under 18 will beaccepted at this time. If you're found to be under 18 you will be removed from the serverimmediately.

Technical Support

What devices and platforms are supported?

Unity SMP runs on Minecraft Java Edition for Windows, Mac, and Linux. We cannot providesupport for Bedrock Edition or Xbox Bedrock Minecraft at this time.

The server seems laggy. Is this normal?

Some lag can occur during peak hours or major events. If you're experiencing consistent lag,try restarting your client first. If the problem persists, report it in our Discord supportchannel.

How do I connect to the server?

We use a third party software to connect to the server. This software creates a secureencrypted connection to the server andensures lower ping for EU players. You can find the download link andinstructions in our Discord server.

How much does this 3rd Party Software cost?

This software can be used for free, however, there is a paid version thatoffers more features. You can find more information about the paid version of Tailscale at their website. We do not enforc TailscalePrivacy Policy, but it is recommended to read it before using the software.

Can I use OptiFine or other performance mods?

Yes! OptiFine and most performance-enhancing mods are allowed and encouraged. Just make surethey don't give you unfair advantages over other players. All mods must comply with ourserver rules.

My game crashed. How do I get help?

Game crashes happen! Please share your crash log in our Discord support channel. Ourtechnical team will do their best to help you identify and fix the issue.

Gameplay & Features

Are there any custom features or plugins?

Yes! We have several quality-of-life plugins and custom features to enhance your gameplayexperience. These include player shops and community events. Join the serverto discover them all!

Can I create shops or trade with other players?

Absolutely! We encourage player-to-player trading and have designated shopping districtswhere you can set up your own shops. Check in-game for more details.

How do I protect my builds?

We run our server entirely on the honor system. Currently, we've had no issues with griefing and have no plans to implement griefing protection at this time.

Are there community projects I can join?

Yes! We regularly organize community builds, events, and collaborative projects. Keep an eyeon our Discord announcements to participate in upcoming projects.

Rules & Moderation

What happens if I break the rules?

Rule violations may result in warnings, temporary bans, or permanent removal from the server,depending on severity. Our moderation team handles each case fairly and individually. Checkour Rules page for moredetails.

How do I report a player or issue?

If you encounter rule violations or have concerns, please report them to our moderatorsthrough Discord. Open a support ticket with details and evidence if possible.

Can I appeal a ban?

Yes, you can submit a ban appeal through our Discord server. Please be honest and respectfulin your appeal, and our team will review it fairly. If you're under the age of 18, you will not receive a chance to appeal a ban and in accordance with the discord rules, you will beremoved from the discord as well.

Community Guidelines

Unity SMP is built on respect, creativity, and collaboration. Please follow these guidelines toensure everyone has a great experience:

Respect & Conduct

  • Treat all community members with kindness and respect
  • No harassment, discrimination, or hate speech of any kind
  • Keep chat appropriate and family-friendly
  • Respect personal boundaries and privacy
  • We're an 18+ server, if you're found to be under 18, you will be banned. No EXCEPTIONS!

Gameplay Rules

  • No griefing or destroying other players' builds without permission
  • No stealing from other players
  • PvP only with mutual consent
  • No exploiting bugs or using hacked clients
  • Keep the world beautiful - clean up after yourself
  • First infraction will result in a temporary ban of at least a week
  • If a player has two infractions, they will receive a permanent ban

Building Guidelines

  • Respect designated community areas and builds
  • Build at least 200 blocks away from other players unless given permission
  • No inappropriate builds or symbols
  • Contribute to community projects when possible

Communication

  • Use Discord for important announcements and discussions
  • Report issues or concerns to moderators privately
  • No spamming in chat or Discord
  • English is the primary language for server chat

Streamer Rules

  • Keep Voice Chat Clean
  • Keep Text Chat Clean
  • Respect the streamer, don't go seek them out
  • English is the primary language for server chat
  • Report issues or concerns to moderators privately

Consequences

Violations of these rules may result in warnings, temporary bans, or permanent removal from theserver, depending on severity. Our moderation team handles each case fairly and individually.

Version 1.21.92

November 9, 2025Latest

✨ General Notes

The server has been successfully switched over to a bare metal machine. The specs currently on the machine are 8GB and two NvME drives.The first drive is 512GB and runs Ubuntu server 24.04 LTS. The second drive is 256NvME and is used for backups only. The server will backup nightly on the controller side and a cron job has been scheduled for the server to backup onto the second NvME drive nightly as well. This will ensure the snapshot will be within 24 hours for all users. The second NvME cron job is scheduled to keep the last 10 back ups - compared to 5 previously on both the controller side and the VM backup side. The server should be much more stable now and we should see less lag spikes and better overall performance. I'll continue to monitor server performance for RAM usage and make a determination if we need to upgrade to 16GB of RAM in the near future. Overall, the server seems to be running much better than before and I expect this to continue. Tailscale was installed directly onto the server and not within the controller of mincraft. Which means if the machine ever looses powers, needs to be rebooted or anything of that nature, Tailscale will automatically restart with the machine and there will be no need to reauthorize the server again. This should make things much easier on everyone. On the networking side I made some changes within the network to ensure the server cannot communicate with other devices for security. I won't go into this any further but there are network securities in place for both myself and you as the user. The new link for the server will be pinned in discord for you. This should be the last Tailscale link you ever need, even on a restart the link will not change. Restarts are now 12 hours apart from one another and you'll still be notified in discord when the server restart was completed and when the server goes back online - this is the same as before. I'll be adding back notifications within discord to notify you within 5 minutes and 1 minute of the server restart, as of this writing this has not been added back in yet. May and w0blie will also be added back as admin access - same as before.

🔧 Improvements

  • Server Moved off a Docker VM to a bare metal machine
  • Tailscale Installed directly onto the machine - no longer dependent on a docker container
  • Server is now standalone
  • RAM usage reduced about 400%
  • Backups increased from 5 to 10 of the whole server
  • Secondary backups now occur nightly on the controller and secondary drive - previously every other day
  • Rendering distance updated from 12 chunks to 16 chunks - in testing there was minimal impact on performance
  • Restarts will now be 12 hours apart 10am MST and 10pm MST - discord notifications will still occur

Monitoring

  • RAM usage - if we need to install more or not
  • Networking Performance and connection issues for users
  • Rendering distance - will it need to be reduced or can it be increased again
